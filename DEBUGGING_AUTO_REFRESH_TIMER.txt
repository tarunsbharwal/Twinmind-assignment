===============================================================================
DEBUGGING REPORT: Auto-Refresh Timer Resetting Issue
===============================================================================

DATE: 2026-04-23
ISSUE: Suggestions do not automatically refresh every 30 seconds during recording.
       Timer resets instead of continuing consistently.

OBSERVATION:
-----------
- When user clicks "Reload suggestions" manually, suggestions appear correctly
- Auto-refresh countdown shows "auto-refresh in 13s" but never triggers
- After 30 seconds, suggestions should auto-refresh but they don't
- Timer appears to reset constantly instead of running to completion

===============================================================================
ROOT CAUSE ANALYSIS
===============================================================================

The issue was in the auto-refresh useEffect hook (app/page.tsx, lines 471-484).

PROBLEM:
--------
The dependency array included session.transcript:

  useEffect(() => {
    if (isRecording) {
      suggestionsTimerRef.current = setInterval(() => {
        generateSuggestions();
      }, 30000);
    }
    return () => {
      if (suggestionsTimerRef.current) {
        clearInterval(suggestionsTimerRef.current);
      }
    };
  }, [isRecording, session.transcript]);  // <- PROBLEM HERE

IMPACT:
-------
1. Interval is created when recording starts (30 second timer begins)
2. After ~10 seconds, a new transcript chunk arrives from audio capture
3. session.transcript changes (new chunk added)
4. useEffect dependency triggers and re-runs the cleanup function
5. clearInterval() destroys the existing interval
6. New interval is created, resetting the 30-second timer
7. Steps 2-6 repeat continuously - timer never completes
8. Result: Auto-refresh never happens, timer constantly resets

TIMELINE VISUALIZATION:
-----------------------
Time    Event                              Interval State
----    -----                              ---------------
0s      Recording starts                   Interval created (0-30s)
10s     Audio chunk processed              Timer at 10s
        → session.transcript updates
        → useEffect runs cleanup            Interval destroyed
        → New interval created              Interval created (0-30s)
13s     Audio chunk processed              Timer at 3s
        → session.transcript updates
        → useEffect runs cleanup            Interval destroyed
        → New interval created              Interval created (0-30s)
...     (repeats every ~10 seconds)        Never reaches 30s

FILE AFFECTED:
--------------
  app/page.tsx - Auto-refresh timer setup

SPECIFIC CODE LOCATION:
  Lines 471-484: useEffect for auto-refresh

DEPENDENCY ISSUE:
-----------------
Including session.transcript in the dependency array causes the effect
to re-run every time the transcript is updated, which happens constantly
during audio capture.

===============================================================================
FIX APPLIED
===============================================================================

CHANGE LOCATION:
  app/page.tsx, line 484 - Dependency array

BEFORE:
-------
  }, [isRecording, session.transcript]);

AFTER:
------
  }, [isRecording]);

EXPLANATION:
------------
The interval only needs to be created/destroyed when recording starts/stops.
It does NOT need to be recreated when the transcript updates.

Why this works:
- generateSuggestions() reads session.transcript directly from state
- No need for transcript in dependencies to trigger the effect
- Only isRecording change should trigger effect setup/cleanup
- Interval now runs uninterrupted for full 30 seconds

DETAILED REASONING:
-------------------
The useEffect has two responsibilities:
  1. Setup: Create interval when isRecording becomes true
  2. Cleanup: Clear interval when isRecording becomes false or component unmounts

Transcript updates don't require re-setup of the interval. The interval
function (generateSuggestions) fetches the current transcript from state
each time it executes, so it always has the latest data.

Including session.transcript in dependencies was premature optimization
that actually broke the feature.

===============================================================================
EXPECTED BEHAVIOR AFTER FIX
===============================================================================

1. User clicks Start recording
2. useEffect runs, creates 30-second interval
3. Transcript chunks arrive every ~10 seconds
4. session.transcript updates but useEffect does NOT re-run
5. Interval continues running uninterrupted
6. At 30 seconds: generateSuggestions() is called automatically
7. Interval resets and waits another 30 seconds
8. Steps 3-7 repeat while recording is active
9. User clicks Stop recording
10. isRecording becomes false
11. useEffect cleanup runs, clearInterval() stops the timer
12. No more auto-refresh until recording starts again

VERIFICATION:
  - Browser console should NOT show interval being recreated constantly
  - "Reload suggestions" button countdown should continue to zero
  - At 30s mark, new suggestions automatically appear
  - This repeats every 30 seconds while recording continues

RELATED CONTEXT
===============================================================================

Auto-refresh Implementation (app/page.tsx, lines 471-484):
  - Uses useRef to store interval ID for cleanup
  - Calls generateSuggestions() every 30000 milliseconds
  - Only active when isRecording is true

Transcript Updates:
  - Occur via handleAudioChunk() when audio arrives
  - Adds new TranscriptChunk to session.transcript
  - Triggered approximately every 30 seconds (chunkDurationMs: 30000)

generateSuggestions() Function:
  - Reads session.transcript and session.suggestionsHistory from state
  - Makes POST request to /api/suggestions endpoint
  - Parses streamed JSON response (after previous fix)
  - Updates session.suggestionsHistory with new suggestions

Session Context:
  - Manages transcript, suggestionsHistory, chatHistory state
  - Provides addTranscriptChunk, addSuggestionBatch functions
  - Used by page component via useSession() hook
