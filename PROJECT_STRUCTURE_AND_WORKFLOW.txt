PROJECT OVERVIEW
================================================================================
This is a Next.js real-time AI meeting assistant that:
1. **Captures audio** from your microphone during meetings
2. **Transcribes audio** using Groq's Whisper API
3. **Generates live suggestions** based on conversation context
4. **Provides chat interface** to ask questions about the meeting

COMPLETE DATA FLOW & WORKFLOW
================================================================================

STEP 1: APP INITIALIZATION
================================================================================

index.html
    ↓
app/layout.tsx                          # Root layout
    ↓
<SessionProvider>                       # Wraps entire app with SessionContext
    ↓
app/page.tsx (Home component)           # Main UI loads

What happens:
- SessionContext loads:
  - Settings from localStorage (if exists)
  - OR uses .env.local API key
  - OR shows empty form
- App shows 3-column layout or Settings modal


STEP 2: USER CLICKS MICROPHONE BUTTON
================================================================================

MicrophoneButton (component)
    ↓
Click handler → startRecording()
    ↓
useAudioCapture hook runs
    ↓
navigator.mediaDevices.getUserMedia()  # Request microphone permission
    ↓
MediaRecorder starts capturing audio

What happens in useAudioCapture.ts:
1. Gets microphone stream from browser
2. Records audio continuously
3. Every 30 seconds, captures a chunk:
   - Stops recording
   - Converts blob to Base64
   - Calls onChunkReady callback
   - Restarts recording


STEP 3: AUDIO CHUNK READY - SEND FOR TRANSCRIPTION
================================================================================

useAudioCapture triggers onChunkReady(audioBase64)
    ↓
app/page.tsx receives the callback
    ↓
handleAudioChunk(audioBase64) function runs
    ↓
Sends POST to /api/transcribe with:
{
  audioBase64: "...",
  apiKey: settings.groqApiKey
}

Backend: app/api/transcribe/route.ts
================================================================================

POST /api/transcribe
    ↓
Extract audioBase64 and apiKey
    ↓
createGroqClient(apiKey)              # Create Groq client
    ↓
groq.transcribe(audioBase64)          # Send to Groq Whisper API
    ↓
Groq returns: { text: "Meeting transcript..." }
    ↓
Return JSON response to frontend


STEP 4: ADD TRANSCRIPT CHUNK TO SESSION
================================================================================

Frontend receives transcribed text
    ↓
Create TranscriptChunk object:
{
  id: unique_id,
  text: "what was said",
  timestamp: "10:30:45 AM",
  duration: 30,
  startTime: Date.now()
}
    ↓
addTranscriptChunk(chunk)             # SessionContext function
    ↓
Updates session.transcript array
    ↓
TranscriptPanel component re-renders
    ↓
Shows new text in left panel


STEP 5: AUTO-GENERATE SUGGESTIONS
================================================================================

After adding transcript chunk
    ↓
generateSuggestions() is called automatically
    ↓
Extracts last 10 transcript items
    ↓
POST to /api/suggestions with:
{
  transcript: "recent conversation...",
  apiKey: settings.groqApiKey,
  systemPrompt: settings.suggestionPrompt,
  recentBatches: [previous suggestions]
}

Backend: app/api/suggestions/route.ts
================================================================================

POST /api/suggestions
    ↓
Creates prompt: systemPrompt + "DO NOT repeat: [recent suggestions]"
    ↓
groq.generateSuggestions(transcript, prompt)
    ↓
Sends to Groq Mixtral-8x7b model
    ↓
Streams response back:
[
  { tag: "ANSWER", preview: "Yes, because..." },
  { tag: "QUESTION", preview: "Have you considered..." },
  { tag: "TALKING_POINT", preview: "Key insight: ..." }
]
    ↓
Frontend parses JSON from stream
    ↓
Creates SuggestionBatch:
{
  id: unique_id,
  generatedAt: timestamp,
  suggestions: [...],
  sourcedFromTranscript: [...]
}
    ↓
addSuggestionBatch(batch)
    ↓
Updates session.suggestionsHistory
    ↓
SuggestionsPanel re-renders
    ↓
Shows 3 new suggestions in middle panel


STEP 6: USER CLICKS ON A SUGGESTION
================================================================================

User clicks on a suggestion card
    ↓
handleSuggestionClick(suggestion) runs
    ↓
Creates ChatMessage:
{
  id: unique_id,
  timestamp: now,
  source: "suggestion",
  message: suggestion.preview,
  relatedSuggestion: suggestion.tag
}
    ↓
addChatMessage(message)               # Add to session.chatHistory
    ↓
Calls generateChatResponse(messageId, message)
    ↓
ChatPanel re-renders, shows user's message


STEP 7: GENERATE CHAT RESPONSE
================================================================================

generateChatResponse(messageId, message) runs
    ↓
Builds context from last 20 transcript items
    ↓
POST to /api/chat with:
{
  message: "Yes, because...",
  transcriptContext: "recent meeting context...",
  apiKey: settings.groqApiKey,
  systemPrompt: settings.chatPrompt
}

Backend: app/api/chat/route.ts
================================================================================

POST /api/chat
    ↓
groq.generateChat(message, transcriptContext, systemPrompt)
    ↓
Sends to Groq Mixtral model
    ↓
Streams response: "Well, the meeting discussed... [streams word by word]"
    ↓
Frontend receives stream
    ↓
Parses Server-Sent Events (SSE format):
data: {"choices":[{"delta":{"content":"Well"}}]}
data: {"choices":[{"delta":{"content":" the"}}]}
data: [DONE]
    ↓
Accumulates text as it streams in
    ↓
updateChatMessageResponse(messageId, fullResponse, latency)
    ↓
Updates ChatMessage with:
{
  ...,
  response: "Well, the meeting discussed...",
  responseLatencyMs: 2340
}
    ↓
ChatPanel re-renders
    ↓
Shows AI response next to user message


STATE MANAGEMENT - SESSIONCONTEXT
================================================================================

contexts/SessionContext.tsx manages all global state:

interface SessionState {
  sessionId: string;              // Unique session ID
  startTime: string;              // When meeting started
  isRecording: boolean;           // Recording status
  transcript: TranscriptChunk[];  // All transcribed text
  suggestionsHistory: SuggestionBatch[];  // All suggestion batches
  chatHistory: ChatMessage[];     // All chat messages
}

interface SessionSettings {
  groqApiKey: string;             // API authentication
  suggestionPrompt: string;       // Custom prompt for suggestions
  chatPrompt: string;             // Custom prompt for chat
  contextWindowSuggestions: number;  // How much context to use
  contextWindowChat: number;      // How much context to use
}

Key functions:
- addTranscriptChunk(chunk) - Add transcribed text
- addSuggestionBatch(batch) - Add suggestions
- addChatMessage(message) - Add chat message
- updateChatMessageResponse(id, response, latency) - Update with AI response
- setSettings(settings) - Save settings to localStorage


API ENDPOINTS SUMMARY
================================================================================

| Endpoint           | Method | Input                              | Output                     | Purpose                 |
|--------------------|--------|-----------------------------------|----------------------------|-------------------------|
| /api/transcribe    | POST   | audioBase64, apiKey               | { text, timestamp }        | Convert audio to text   |
| /api/suggestions   | POST   | transcript, apiKey, systemPrompt  | Streamed [suggestions]     | Generate 3 suggestions  |
| /api/chat          | POST   | message, context, apiKey          | Streamed response          | Generate detailed answer|


GROQ API CLIENT - lib/groq.ts
================================================================================

class GroqClient {
  // Transcription
  transcribe(audioBase64)
    → POST /audio/transcriptions
    → model: "whisper-large-v3-turbo"
    → Returns: { text: string }

  // Suggestions
  generateSuggestions(transcript, systemPrompt)
    → POST /chat/completions
    → model: "mixtral-8x7b-32768"
    → stream: true
    → Returns: ReadableStream

  // Chat
  generateChat(message, context, systemPrompt)
    → POST /chat/completions
    → model: "mixtral-8x7b-32768"
    → stream: true
    → Returns: ReadableStream
}

SECURITY & SETTINGS
================================================================================

- API Key: Stored in localStorage (only on this device)
- .env.local: Auto-loads on startup (added to .gitignore)
- No server-side storage: Everything runs on client + Groq API
- Sessions: Stored in browser only (refreshing clears data)

FILE DESCRIPTIONS
================================================================================

app/layout.tsx
- Root layout file
- Wraps entire app with SessionProvider
- Provides global session state to all components

app/page.tsx
- Main UI component
- 3-column layout: Transcript | Suggestions | Chat
- Handles all user interactions and API calls
- Manages recording state, suggestion generation, chat responses

app/api/transcribe/route.ts
- Receives audio chunks in Base64 format
- Calls Groq Whisper API for transcription
- Returns transcribed text

app/api/suggestions/route.ts
- Receives transcript and generates suggestions
- Calls Groq Mixtral API for suggestion generation
- Returns streamed JSON with 3 suggestions

app/api/chat/route.ts
- Receives user message and transcript context
- Calls Groq Mixtral API for chat response
- Returns streamed chat response

contexts/SessionContext.tsx
- React Context for global state management
- Provides SessionState (transcript, suggestions, chat)
- Provides SessionSettings (API key, prompts)
- Functions to add/update session data
- Persists settings to localStorage

hooks/useAudioCapture.ts
- Custom React hook for audio recording
- Uses browser's MediaRecorder API
- Captures audio in 30-second chunks
- Converts to Base64 for transmission

components/MicrophoneButton.tsx
- Button to start/stop recording
- Shows recording status

components/TranscriptPanel.tsx
- Displays all transcribed text
- Shows timestamp for each chunk
- Auto-scrolls to latest content

components/SuggestionsPanel.tsx
- Shows current suggestion batch (3 suggestions)
- Shows previous suggestions below
- Click handler to select suggestion

components/ChatPanel.tsx
- Chat message history
- Message input field
- Shows user messages and AI responses
- Shows response latency

components/SettingsModal.tsx
- Modal dialog for configuration
- Input field for Groq API key
- Context window sliders
- Advanced prompt customization

lib/types.ts
- TypeScript interfaces for all data structures
- TranscriptChunk, Suggestion, SuggestionBatch
- ChatMessage, SessionState, SessionSettings

lib/groq.ts
- GroqClient class for API communication
- transcribe() - Sends audio to Whisper API
- generateSuggestions() - Gets suggestions from Mixtral
- generateChat() - Gets chat response from Mixtral

lib/prompts.ts
- DEFAULT_PROMPTS - AI system prompts
- DEFAULT_CONTEXT_WINDOWS - Token limits
- GROQ_MODELS - Model names used

lib/export.ts
- downloadSessionJSON() function
- Converts session to exportable JSON format
- Triggers browser download

.env.local
- Stores NEXT_PUBLIC_GROQ_API_KEY
- Loaded on app startup
- Not committed to git (in .gitignore)
